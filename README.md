# The Inversion of Greatness: archival deposit

Archival deposit for *The Inversion of Greatness: From the Nature of Necessity to Maximum Possibility*, by Procyon. Pre-release v0.2.6. The book is read in full at https://inversionofgreatness.org; this deposit holds the four files for this version.

## Files

- `the-inversion-of-greatness.epub`: the book as an EPUB, with notes and the bibliography.
- `the-inversion-of-greatness.pdf`: the book as a PDF.
- `the-inversion-of-greatness-llms.txt`: the full text as plain text, for reading by software.
- `the-inversion-of-greatness-lean.zip`: the Lean 4 project that checks the proof from its stated premises (sources, `PREMISES.md`, `OUTSIDE-MAP.md` and setup files; the Mathlib cache is not included). It includes the onset theorem, the joined capstone, and the capacity route to necessary change, with conditional alternatives identified in the premise ledger. The archive comes from source commit `baba9c828685e6a98a3ca684b1ac793e8203250f` and pins Lean 4.8.0.

The EPUB, PDF and plain text carry the release version. The Lean ZIP carries its source and toolchain pins. `.zenodo.json` records the release version and publication date.
