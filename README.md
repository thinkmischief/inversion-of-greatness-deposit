# The Inversion of Greatness: archival deposit

Archival deposit for *The Inversion of Greatness: From the Nature of Necessity to Maximum Possibility*, by Procyon. Pre-release v0.2.5. The book is read in full at https://inversionofgreatness.org; this deposit holds byte-identical copies of the files the site offers for download.

## Files

- `the-inversion-of-greatness.epub`: the book as an EPUB, with notes and the bibliography.
- `the-inversion-of-greatness.pdf`: the book as a PDF.
- `the-inversion-of-greatness-llms.txt`: the full text as plain text, for reading by software.
- `the-inversion-of-greatness-core.txt`: a condensed plain-text version of the argument.
- `the-inversion-of-greatness-lean.zip`: the Lean 4 project that checks the proof from its stated premises (sources, `PREMISES.md`, `OUTSIDE-MAP.md` and setup files; the Mathlib cache is not included). Its bridge premise for the reflective route is named `attentionCrossesRealSeparation`, matching the book’s *Attention Crosses a Real Separation* (called *Intentional Traversability* before v0.2.5); the project builds cleanly with Lean 4.8.0.

Each file carries the version it was built for; `.zenodo.json` carries the same version and the publication date.

## Citing

Cite the concept DOI by default; it identifies the work across versions. Cite a version DOI only when an exact archived snapshot matters. See https://inversionofgreatness.org/how-to-cite.
